# COSA È INCLUSO E COSA SERVE ANCORA

## Incluso

54 cartelle con `SKILL.md`, le risorse realmente disponibili al momento dell’esportazione, profili condivisi recuperati, script, modelli, immagini e font già presenti nelle skill, catalogo leggibile e JSON. La cartella `shared/` conserva risorse storiche senza farle diventare una55ª skill.

## Non incluso automaticamente

- Repository completi delle app, database, dati studenti, sessioni, account, credenziali o configurazione dei servizi.
- Tutti i PDF/audio/progetti citati nei vecchi percorsi. Alcune skill sono procedure e non contengono il software su cui lavorano.
- Strumenti di generazione/ricerca/deploy disponibili solo in un ambiente specifico. Le istruzioni su tali strumenti non ne installano le funzionalità.
- Pacchetti Python, Node o FFmpeg: installarli soltanto se richiesti dal lavoro selezionato. Gli elenchi requirements sono profili pratici, non lockfile universali.

`catalogo/dipendenze-esterne.json` censisce170 percorsi storici distinti, compresi input/output/esempi: non considerarli170 file obbligatori mancanti. Per ricostruire una app verificare e clonare il suo repository sorgente autorizzato. Per creare un nuovo documento fornire il contenuto, selezionare un modello e verificare i font.

## Risorse parziali e storiche

Alcuni profili consolidati dichiaravano risorse mancanti. Conservare l’avvertenza: il recupero di una skill omonima in questa raccolta non prova che qualunque app sia ricostruibile. Consultare la skill specifica e verificare i file effettivi. Gli script sotto `references/originali/` sono storico; non prevalgono sulla procedura aggiornata.

Le istruzioni specialistiche non sono state tutte eseguite: non sono stati ricostruiti54 progetti, generati media a pagamento, avviati deploy o chiamate API. I collaudi di questo archivio riguardano struttura, integrità, metadati, link attivi, sicurezza statica, preparazione portabile e smoke test offline di risorse selezionate.
