# Presentazione breve di un'app per il blog — DOCX

Fonte parziale: descrizione consolidata dello stile personale; manca lo
script originale genera_presentazione.py. Per produrre il file usare la
skill generale documents e un generatore salvato prima dell'esecuzione.
Non dichiarare quello script incluso o la formattazione byte-identica.

## Formato fisso

- Titolo + UN paragrafo, circa150parole.
- MASSIMO15righe complessive, verificando il rendering con font/margini reali.
- Niente immagini, box o sottosezioni salvo richiesta esplicita.
- Stile personale chiaro e pratico, riferimento al post dell'app di Latino.
- Hyperlink cliccabile all'app nell'effettivo DOCX, non solo URL come testo.

Descrivere cosa fa l'app, destinatari e utilità didattica senza promesse di
correttezza totale, certificazioni BES o funzioni non verificate. Visitare
l'URL indicato e leggere l'app se serve conoscerla; non pubblicare il post
per il solo fatto di avere creato il DOCX. Consegnare il DOCX; non convertirlo
in PDF se non richiesto. Per l'installazione del riordino tenere l'originale
finché manca il suo generatore se si vuole riproduzione esatta del layout.
